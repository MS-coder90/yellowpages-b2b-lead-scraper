# 🚀 Advanced YellowPages B2B Lead Scraper

An enterprise-grade Python data pipeline engineered to extract high-value B2B lead directories from YellowPages layouts and export them seamlessly into structured Microsoft Excel matrices. Built for professional marketing outreach and competitive market intelligence.

## 🛠️ Tech Stack & Architecture
- **Language:** Python 3
- **Parser Engine:** BeautifulSoup (BS4) for structural DOM parsing
- **Data Matrix Pipeline:** Pandas for data manipulation & cleaning
- **Storage Blueprint:** OpenPyXL for formatted `.xlsx` matrix generation

## 📊 Feature Extraction Grid
The automated pipeline parses the layout to compile critical business datasets:
- **Business Name** (Verified Corporate Identity)
- **Phone Number** (Direct B2B Contact Channels)
- **Website Link** (Official Web Domains)
- **Physical Address** (Localized Geolocation Coordinates)

## 📁 How To Run
1. Clone the repository
2. Install dependencies: `pip install pandas beautifulsoup4 openpyxl`
3. Execute the script: `python b2b_master_scraper.py`
